# Control Systems Learning with Python

This folder contains your journey to learn control systems using Python.

## 🚀 Quick Start

### 1. Install Python
- Download from [python.org](https://www.python.org/downloads/)
- **Important**: Check "Add Python to PATH" during installation

### 2. Set Up Environment
After installing Python, run:
```powershell
cd "C:\Sukumaran_Work\ControlSystem_study\Training"
python setup_environment.py
```

### 3. Create Virtual Environment (Recommended)
```powershell
python -m venv control_systems_env
control_systems_env\Scripts\Activate.ps1
pip install -r requirements.txt
```

### 4. Start Learning
```powershell
jupyter notebook
```
